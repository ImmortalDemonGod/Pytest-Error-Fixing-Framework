# 02 — Static Audit

_88 findings, each surviving an independent adversarial falsification pass. Auditable surface: 183 files. Severity: 1 critical / 5 high / 34 medium / 48 low._

**Judged against provisional intent:** PROVISIONAL: This project is an AI-powered automated pytest test fixer. Its purpose is to take a Python repository with failing pytest tests and, without human intervention, generate correct fixes for each failure and submit them as pull requests. The system discovers failures with pytest, formulates LLM prompts (via OpenRouter/LiteLLM) using an analyze-before-fix pipeline, applies code changes with full backup/restore safety, verifies fixes by re-running pytest in a clean subprocess, and creates git branches and pull requests for successful fixes. A secondary feature generates property-based tests using Hypothesis (and optionally LLMs) for untested Python source files. The long-term aspiration visible in the design documents and ai-manager-ideas submodules is to approach SWE-Bench-level autonomous software engineering — automatically finding and fixing real bugs in Python codebases with high accuracy, competing with systems like Aider. Stage 4 refinement should validate whether the SWE-bench framing is still active or if the project has pivoted to a narrower tool-assisted developer-workflow scope.
